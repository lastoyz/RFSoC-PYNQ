# Common Troubleshooting

## 목적

보드 bring-up, overlay 로딩, 기능 테스트 중 자주 발생하는 문제를 빠르게 분류하고 대응한다.

## 1) 부팅이 되지 않음

증상:

- 전원 인가 후 부팅 진행 없음
- UART 로그가 초기에 멈춤

확인:

- 부트 모드(DIP) 설정
- SD 카드 이미지/쓰기 상태
- 전원 어댑터 정격 및 케이블 접촉

대응:

- SD 카드 재이미징 후 재시도
- 최소 연결(전원 + UART)로 단순화하여 재부팅

## 2) 네트워크 접속 불가

증상:

- Jupyter/SSH 접속 불가
- 보드 IP 확인 불가

확인:

- 링크 LED 상태
- DHCP 할당 여부
- PC/보드 동일 대역 여부

대응:

- 라우터 DHCP 목록에서 IP 확인
- Ethernet 케이블/포트 교체
- 필요 시 UART로 로그인해 네트워크 상태 점검
- USB Ethernet Gadget 사용 시 고정 접속 주소 `192.168.3.1` 경로 확인

## 3) Overlay 로딩 실패

증상:

- overlay 로딩 시 예외 발생
- IP 접근 실패

확인:

- `.bit`/`.hwh` 파일 쌍 일치
- 파일 배치 경로/권한
- 보드와 산출물 대상 보드 일치 여부

대응:

- 같은 빌드 산출물 세트로 재배치
- 보드 재부팅 후 재로딩
- 필요 시 `fpga-board-vivado-setup.md` 절차로 재빌드

## 4) 노트북 테스트 실패

증상:

- import 오류
- 노트북 셀 실행 중 장치 접근 실패

확인:

- 이미지/PYNQ 버전 호환성
- 패키지 설치 상태
- 선행 overlay 로딩 여부

대응:

- 커널 재시작 후 재실행
- 의존성 재설치/버전 고정
- 실패 셀 로그와 재현 절차 기록

## 5) SD 이미지 빌드 실패

증상:

- `make BOARD=<BOARD>` 중 중단
- BSP/도구 버전 관련 오류

확인:

- Ubuntu/Vivado/PetaLinux 버전
- `boards/<BOARD>/<BOARD>.bsp` 파일 존재
- 외부 다운로드 파일 접근 가능 여부

대응:

- `README.md`, `sd-image-build.md` 요구사항 재확인
- BSP 재배치 후 재빌드
- 환경 스크립트/경로 설정 재점검

## 기록 원칙

- 실패 증상, 로그, 재현 절차, 시도한 조치, 결과를 함께 기록
- 반복 이슈는 별도 이슈 문서로 분리하여 누적 관리
