# FW Setup Deep Dive

## 목적

`fpga-board-vivado-setup.md`에서 생성한 `.bit/.hwh`를 보드 실행환경에 반영하고, overlay 로딩 안정성을 점검한다.

## 범위

- Overlay 파일 배치
- Overlay 로딩 전후 점검
- 초기 부팅/접속/로그 확인
- 제외: bitstream/hwh 생성(빌드 단계), 기능 테스트 시나리오 실행

## 선행 문서

- 빌드 절차: `fpga-board-vivado-setup.md`
- 전체 단계: `guides/README.md`

## 단계

### 1) 아티팩트 준비

- 빌드 산출물 `.bit`, `.hwh` 존재 여부만 확인
- 파일명과 overlay 이름 일치 여부 확인
- 이전 산출물과 혼동되지 않도록 버전 태깅

### 2) 보드 환경 반영

- 보드에서 사용하는 overlay 디렉터리로 파일 배치
- 파일 권한/소유권 확인 (필요 시)
- 기존 동명 파일 백업 후 교체

### 3) 로딩 전 점검

- 보드 재부팅 후 접속 확인 (Jupyter/SSH 등)
- 디스크 여유 공간 확인
- 관련 서비스 상태 확인

### 4) Overlay 로딩

- PYNQ에서 overlay 로딩 수행
- 로딩 시 예외/경고 메시지 확인
- 로딩 직후 기본 IP 접근 확인

### 5) FW 레벨 스모크 체크

- 필수 디바이스 노드/드라이버 인식 여부 점검
- 클럭/리셋 관련 오류 로그 여부 확인
- 필요 시 재부팅 후 재로딩 재현성 확인

## 완료 기준

- overlay 로딩이 안정적으로 성공
- 재부팅 후에도 동일 절차로 재현 가능
- 치명 로그 없이 SW 기능 테스트 단계로 진행 가능
